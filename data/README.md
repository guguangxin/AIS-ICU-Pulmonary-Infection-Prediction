# Data directory

Participant-level clinical data are intentionally **not included** in this public repository.

The analysis scripts expect an authorized local analysis-ready CSV named `BSAfree_feature_selection_input_exactsplit.csv`, or a path supplied through the `AIS_ICU_DATA_FILE` environment variable.

Do not commit patient-level CSV/XLSX files, identifiers, medical record numbers, exact patient-level dates, or source-record exports to the public repository.
