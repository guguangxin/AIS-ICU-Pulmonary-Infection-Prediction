# Historical BSA-inclusive Tables S11-S12

This directory contains the table-only reconstruction code for the historical exploratory BSA-inclusive 10-predictor analysis retained in the Supplementary Material.

## Scope

The archived 10-predictor analysis code can continue to generate historical Figures S2, S4, S5, and S6. The script here is focused on Supplementary Tables S11 and S12:

- `historical_BSA_TableS11_S12.py`

It compares fixed-test calibrated probabilities from:

1. the historical BSA-inclusive 10-predictor models; and
2. the current BSA-free 11-predictor primary models.

No patient-level prediction file is included in the public repository.

## Required local inputs

Prefer the patient-level calibrated prediction CSV generated by each modeling workflow, typically named:

`测试集逐患者预测概率_校准后_带StudyRowID.csv`

Each file should contain `Study_row_id`, the binary true label, and calibrated probabilities for all eight algorithms.

## Example

```bash
python historical_BSA_TableS11_S12.py \
  --historical "<restricted-path>/BSA10/测试集逐患者预测概率_校准后_带StudyRowID.csv" \
  --primary11 "<restricted-path>/Primary11/测试集逐患者预测概率_校准后_带StudyRowID.csv"
```

Generated outputs are written under `outputs/historical_bsa_table_s11_s12/` by default and should not be committed publicly.

## Statistical conventions

- Fixed internal test set: n=1,011, events=407.
- AUC intervals: 1,000 patient-level bootstrap resamples, seed 42, percentile 95% intervals.
- Calibration intercept and slope use the same definitions as the current primary modeling code.
- Table S11 reports a descriptive delta AUC (`Primary11 - historical BSA+`) and does **not** use an isolated-BSA paired hypothesis test, because the two predictor sets differ beyond BSA after BSA-free re-selection.
